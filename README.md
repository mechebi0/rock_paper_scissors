# Rock Paper Scissors - Python Console Game

A classic Rock-Paper-Scissors game built in Python that runs entirely in the terminal. Play against the computer in a best-of-3 format — make your choice, see the computer's pick, and track who wins each round!

Perfect quick portfolio project to showcase Python fundamentals.

## Why This Project?
- Recreates one of the most iconic hand games with simple logic.
- Demonstrates functions, conditionals, loops, random selection, and input validation.
- Completed in under 30 minutes — great for beginners.

## Technologies Used
- **Language**: Python 3.8+
- **Modules**: `random`
- **IDE**: PyCharm

## Features
- Best-of-3 rounds with score tracking
- Input validation (accepts only "rock", "paper", "scissors")
- Clear winner determination logic
- Fun, readable console messages
- Modular code with separate functions
